## WHAT LUXURY MEANS HERE
NOT: gradients, glassmorphism, animation excess, generic SaaS templates
YES: clarity, white space, typographic discipline, exceptional imagery, confidence

## BEFORE ANY VISUAL CHANGE
1. Screenshot baseline (mobile + tablet + desktop)
2. Define what problem is being solved
3. Measure conversion impact if changing CTA or form
4. Test on real devices (iOS Safari + Chrome Android minimum)
5. Verify WCAG AA contrast ratios

## COMPONENT RULES
- Button: always `type="button"` unless explicitly submit
- Images: next/image with proper alt text
- Icons: SVG with aria-label
- Forms: proper label association, error states, success states
- Links: descriptive text (not "click here")

## NEVER
- Redesign working components for novelty
- Add animation that serves no user purpose
- Use fake scarcity/urgency UI patterns
- Reduce white space to fit more content
