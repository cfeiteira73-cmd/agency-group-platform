## THE ABSOLUTE RULE

**NEVER DESTROY EXISTING EXCELLENCE.**

If a proposed change would degrade any PE element — stop. Understand why. Find an alternative that improves the system without degrading what works.

The 9 questions before any change:
1. Is AG better after this than before?
2. Does this advance the €1B path?
3. Does this protect existing excellence?
4. Does this improve a commercially meaningful metric?
5. Is this the highest-value action available?
6. Does this build a compounding asset?
7. Could a competitor replicate this in < 30 days?
8. Does this generate or preserve real data?
9. Is this ready for HNWI first impression?

Majority NO = do not ship.
